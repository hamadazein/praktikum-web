# Praktika learning platform

User requests a new clone and a complete enjoyable, accessible learning UI. New checkout: C:/Users/hamad/Documents/praktikum-web. Existing Weblab checkout remains independent.

## Approach
Retain static HTML hosting and original tutorials. Build a small native-module app using generated curriculum/content JSON. A simple reskin would leave practice disconnected; introducing a backend would create setup friction without benefiting the core learning task.

## Deliverables
1. Distinct responsive home with interactive HTML/CSS/JS build demonstration.
2. Seven actual modules, 28 canonical exercise files, searchable titles and topics.
3. In-app Markdown reader, module objectives, original source viewer, downloads and live-demo links for browser lessons. PHP source served from JSON so it is never falsely presented as executable HTML.
4. Per-exercise completion, module bookmarks, quiz explanation and persistent progress.
5. Native HTML/CSS/JS playground, sample challenges, draft storage, reset confirmation, download and sandboxed output. Source of simple HTML/CSS exercises can be imported.
6. Progress view and all available projects, reusable accessible navigation and preferences.
7. Legacy anchors and back-button point to new module pages.

## Testing
Node tests check manifest paths, source bundles, idempotent progress, wrong-answer handling and corrupt/blocked storage. Playwright covers practice, quiz, search, sandbox, original sources, PHP information, bookmarks, responsive layouts, keyboard shortcuts, and WCAG A/AA automated checks. Screenshots reviewed on desktop and mobile.

## Constraints
No fabricated accounts, activity or unavailable future modules. No PHP execution claimed on a static host. Original demo dependencies may require internet; the main application and playground presets use bundled assets. Preserve source tutorials. Use requested font stack and local Inter. No remote publication in this request.
