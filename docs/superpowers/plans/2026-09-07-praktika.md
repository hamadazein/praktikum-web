# Praktika implementation plan

**Goal:** Deliver a complete static practice platform using the seven existing meetings.

**Architecture:** Native browser modules; build-time curriculum and JSON source bundles; sanitized Markdown; browser-local state; isolated JavaScript preview.

**Tech stack:** HTML/CSS/JavaScript, Node, Marked, DOMPurify, Inter, Playwright and axe.

## Tasks
- [x] Build tools and manifest: scripts/curriculum.mjs defines verified titles/objectives/quiz. scripts/build.mjs validates all files and generates assets/data. Test source counts, duplicate exclusions and PHP text representation.
- [x] State: assets/js/state.mjs implements completion, saved modules, quiz results, preferences and resume; unit test repeated operations, data recovery and blocked storage.
- [x] UI: index.html, assets/styles.css, assets/js/app.mjs and views.mjs provide navigation, home, catalog, module, projects, saved, progress and accessible states.
- [x] Learning: assets/js/learning.mjs renders Markdown and source viewer, marks exercises, checks quiz answers and connects simple sources to playground.
- [x] Playground: assets/js/playground.mjs provides three code editors, preview, draft, reset, presets and download; assets/js/sandbox.mjs builds isolated previews and reports runtime errors safely.
- [x] Verify with npm run build, npm test, npm run test:e2e, npm run format:check and screenshots. Document localhost port 4174 and static/PHP hosting differences.
